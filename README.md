# Carry-On Trailer Mobile Scanning ROI Calculator v2.0

A comprehensive business case calculator for implementing smartphone-based scanning vs. Zebra hardware across Carry-On's manufacturing network.

## Features

- **Current → Future State Modeling**: Show before/after time savings with percentage improvements
- **Professional Scenario Planning**: Conservative/Realistic/Optimistic with customizable presets
- **Complete Save/Load System**: Named scenarios and scenario slot customization
- **Audit-Compliant Baseline**: True "no change" scenario showing negative ROI
- **Interactive Charts**: Real-time benefits breakdown and 4-year financial analysis
- **Professional Export**: PDF and Excel with detailed breakdowns
- **Faye Brand Integration**: Professional color palette and logo

## Quick Start

1. Open `index.html` in any modern web browser
2. Adjust parameters using interactive sliders
3. Switch between Conservative/Realistic/Optimistic scenarios
4. Save custom scenarios for later comparison
5. Export results to PDF or Excel
